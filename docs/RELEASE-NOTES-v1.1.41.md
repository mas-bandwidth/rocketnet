# RocketNet v1.1.41

Changes compared with the `v1.1.40` tag. A point release: no configuration,
export, counter, packet layout or protocol version change, and v1.1.41
endpoints interoperate with every v1.x endpoint.

- Build and test infrastructure only: the functional test legs run in three
  parallel shards each. The library is unchanged.

- Tag: `v1.1.41`, on the merged `main` commit.
- Release: [GitHub release](https://github.com/mas-bandwidth/rocketnet/releases/tag/v1.1.41).
