# RocketNet v1.1.18

Changes compared with the `v1.1.17` tag. A point release: no configuration,
export, counter, packet layout or protocol version change, and v1.1.18
endpoints interoperate with every v1.x endpoint.

- Windows RIO transport: a bind refused with WSAENOBUFS reports out of memory.

- Tag: `v1.1.18`, on the merged `main` commit.
- Release: [GitHub release](https://github.com/mas-bandwidth/rocketnet/releases/tag/v1.1.18).
