# RocketNet v1.1.22

Changes compared with the `v1.1.21` tag. A point release: no configuration,
export, counter, packet layout or protocol version change, and v1.1.22
endpoints interoperate with every v1.x endpoint.

- Verification: the trace-check infrastructure, which checks that a run of the
  code is a behaviour of its TLA+ model, with a worked example. Tests and tools
  only; the library is unchanged.

- Tag: `v1.1.22`, on the merged `main` commit.
- Release: [GitHub release](https://github.com/mas-bandwidth/rocketnet/releases/tag/v1.1.22).
