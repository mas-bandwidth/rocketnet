# RocketNet v1.1.19

Changes compared with the `v1.1.18` tag. A point release: no configuration,
export, counter, packet layout or protocol version change, and v1.1.19
endpoints interoperate with every v1.x endpoint.

- Counters: the counter class names and the four counter block readers are
  available in every build, not only development builds.

- Tag: `v1.1.19`, on the merged `main` commit.
- Release: [GitHub release](https://github.com/mas-bandwidth/rocketnet/releases/tag/v1.1.19).
