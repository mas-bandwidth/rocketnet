# RocketNet v1.1.34

Changes compared with the `v1.1.33` tag. A point release: no configuration,
export, counter, packet layout or protocol version change, and v1.1.34
endpoints interoperate with every v1.x endpoint.

- Tests only: the server bind address functional tests start their control
  servers on a port the system picks instead of rebinding a port another
  process may have taken. The library is unchanged.

- Tag: `v1.1.34`, on the merged `main` commit.
- Release: [GitHub release](https://github.com/mas-bandwidth/rocketnet/releases/tag/v1.1.34).
