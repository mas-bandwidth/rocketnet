# RocketNet v1.1.23

Changes compared with the `v1.1.22` tag. A point release: no configuration,
export, counter, packet layout or protocol version change, and v1.1.23
endpoints interoperate with every v1.x endpoint.

- Tests: a gso functional test derives its overflow figure from the transport
  constant instead of a fixed number. The library is unchanged.

- Tag: `v1.1.23`, on the merged `main` commit.
- Release: [GitHub release](https://github.com/mas-bandwidth/rocketnet/releases/tag/v1.1.23).
