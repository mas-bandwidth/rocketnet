# RocketNet v1.1.27

Changes compared with the `v1.1.26` tag. A point release: no configuration,
export, counter, packet layout or protocol version change, and v1.1.27
endpoints interoperate with every v1.x endpoint.

- Build and test infrastructure only: the Linux Debug unit suite runs in two
  shards. The library is unchanged.

- Tag: `v1.1.27`, on the merged `main` commit.
- Release: [GitHub release](https://github.com/mas-bandwidth/rocketnet/releases/tag/v1.1.27).
