# RocketNet v1.1.39

Changes compared with the `v1.1.38` tag. A point release: no configuration,
export, counter, packet layout or protocol version change, and v1.1.39
endpoints interoperate with every v1.x endpoint.

- Load test: the server load test tool (`harden_load`) gains flags for the
  game-thread frame shape: the send and update forms the game uses, and the
  row script follows. Test tooling and documentation only; the library is
  unchanged.

- Tag: `v1.1.39`, on the merged `main` commit.
- Release: [GitHub release](https://github.com/mas-bandwidth/rocketnet/releases/tag/v1.1.39).
