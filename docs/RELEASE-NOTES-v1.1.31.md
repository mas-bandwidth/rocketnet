# RocketNet v1.1.31

Changes compared with the `v1.1.30` tag. A point release: no configuration,
export, counter, packet layout or protocol version change, and v1.1.31
endpoints interoperate with every v1.x endpoint.

- Build and test infrastructure only: the lint job runs in four parallel
  shards. The library is unchanged.

- Tag: `v1.1.31`, on the merged `main` commit.
- Release: [GitHub release](https://github.com/mas-bandwidth/rocketnet/releases/tag/v1.1.31).
