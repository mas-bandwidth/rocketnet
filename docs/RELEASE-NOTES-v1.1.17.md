# RocketNet v1.1.17

Changes compared with the `v1.1.16` tag. A point release: no configuration,
export, counter, packet layout or protocol version change, and v1.1.17
endpoints interoperate with every v1.x endpoint.

- Windows RIO transport: a failed create restores the bind address and port it was given.

- Tag: `v1.1.17`, on the merged `main` commit.
- Release: [GitHub release](https://github.com/mas-bandwidth/rocketnet/releases/tag/v1.1.17).
