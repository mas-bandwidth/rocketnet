# tools/msan_known.txt: the known MemorySanitizer findings for the portable
# unit suite. A finding is keyed by an in-tree frame of one MemorySanitizer
# warning, in the form the gate prints: its top frame (function and source
# location) when that frame is in this tree, else the top frame, ` | `, and
# the first in-tree frame below it, for example
#   bcmp (bin/test) | some_check(int) tests/test_unit_x.cpp:12:5
# A binary-only frame is written `(bin/test)` and a C++ library frame under
# `include/c++/` (libstdc++'s headers as include/c++/<file>, the instrumented
# libc++'s, from any install prefix, as include/c++/v1/<file>); neither is
# in-tree, for example
#   std::__1::basic_string<char>::size() include/c++/v1/string:1180:5 | some_check(int) tests/test_unit_x.cpp:12:5 An entry that names no in-tree frame
# (function and file:line under this tree) fails the gate on every run: a
# top frame alone would pass every later warning with that top frame. A
# warning whose key is absent here fails `bash tools/run_msan.sh`. The gate
# passes when the run is clean or every finding is listed.
#
# The list is empty: the gate runs clean with clang 18.1.3 and 21.1.8. The
# findings it used to hold were blind spots, each fixed at its cause:
#
# - sodium's raw syscall(SYS_getrandom) fill and libc's explicit_bzero wipe
#   wrote memory MSan cannot see; under MSan the generator's
#   SANITIZER_ADAPTATIONS unpoison exactly the bytes each one wrote
#   (tools/generate_sodium.py, sodium/README.md).
# - the system libstdc++ is not instrumented; the gate links the
#   MSan-instrumented libc++ (tools/build_msan_libcxx.sh).
# - three tests compared or scanned bytes nothing had written (a region's
#   unused memory, a caller's arena block, a reassembly set's staging); each
#   now starts those bytes zeroed. More of that shape (2026-11-12): every
#   case that compares a whole connection region around a refused send
#   (mo_send_side_check_refused, and the room-watch case's own compare) now
#   builds its objects in zeroed blocks (mo_pair_setup_zeroed,
#   rn_unit_arena_create_zeroed).
#
# A new entry is a finding with a written cause, never a line to make the
# gate green: fix the cause where it can be fixed.
