# Every functional-suite row a CI leg is allowed to skip, and why.
#
# The functional suite leaves out a row whose runs_here predicate is false on
# the host and prints "SKIPPED <case>: <predicate>", then "skipped: <n>"
# (tests/suite_runner.h, suite_print_skipped). A whole-suite run in CI goes
# through tools/run_functional.sh <variant>, which runs the suite and then
# tools/check_skips.py on its output. The check fails on:
#   - a SKIPPED line this file does not list for the leg (a row that stopped
#     running: a lost capability, a predicate that went false, a new row
#     that never runs here);
#   - a row listed for the leg that ran instead (the list is exact both ways,
#     so a stale row cannot hide a later skip);
#   - a predicate other than the one listed;
#   - output with no "skipped: <n>" line, or one that disagrees with the
#     SKIPPED lines (the suite did not finish, or this was not a whole run).
#
# A leg is <os>-<variant>: the os is read from the host (linux, macos,
# windows), the variant is run_functional.sh's first argument, and the
# server pin is read from ROCKETNET_SERVER_TRANSPORT (auto when unset), which
# must match the leg's. check_skips.py --lint (lint job) fails on a leg no
# workflow runs, a variant a workflow runs that no leg declares, a whole-suite
# run in a workflow that does not go through run_functional.sh, a predicate
# with no reason, and a case or predicate the sources do not name.
#
# The rows were taken from the CI and nightly logs at 76edea48e (v1.1.7):
# ci.yml 43219579414, Nightly CI 43219875485, nightly.yml 43219892575,
# nightly-examples 43168317247, nightly-leaks 43168918451, nightly-macos-
# sanitizers 43170188115, nightly-bigendian-system 43208118230.
#
#   leg <name> <os> <server pin>       where it runs
#   reason <predicate> <text>          why a row with this predicate may skip
#   skip <case> <predicate> <legs>     the legs (comma-separated) that skip it
